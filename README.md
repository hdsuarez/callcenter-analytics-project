# Project Overview

# 

This project analyzes call center operations using Python (ETL) and Power BI (Data Visualization) to uncover insights about agent performance, customer interactions, and operational efficiency.



The goal is to transform raw interaction data into actionable business insights through a clean data pipeline and an interactive dashboard.

Call Center Analytics Dashboard (Fase 2) 

Proyecto de análisis de operaciones de Call Center desarrollado con Python, Pandas, Streamlit y Power BI.

Características:

- ETL automatizado
- Limpieza de datos
- KPI SLA
- Ranking de agentes
- Identificación de agentes críticos
- Performance por canal
- Executive Summary
- Dashboard interactivo

Tecnologías:

- Python
- Pandas
- Streamlit
- Power BI
- GitHub
